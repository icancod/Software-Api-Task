# Software Api Task  
**Agent Call Tracker App**

This project is a **simple web application** that tracks and displays **connected and not connected calls** made by agents within a specified timeframe using an API backend.

The frontend uses **HTML, CSS, and JavaScript**, while the backend API runs on **Node.js** and connects to a **MongoDB Atlas** database.

---

## 📌 Overview

**Agent Call Tracker** helps you:

- Track agent calls over time  
- Display connected vs not connected call counts  
- Organize real-time call data via API  

This project is built as part of a software task to demonstrate full-stack API usage with a frontend UI and backend data storage. :contentReference[oaicite:0]{index=0}
